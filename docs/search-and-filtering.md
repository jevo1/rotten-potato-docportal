## Functional Description
The **Search and Filtering** module enables users to quickly find specific artworks or artists that match their interests and budget. It provides a robust discovery experience across the marketplace.

Key features include:
- **Instant Search:** Full-text search for artwork titles and descriptions.
- **Categorical Filters:** Narrow results by art style (e.g., Digital, Traditional, Sculpture).
- **Sorting Options:** Organize results by Newest, Popularity, or Price (Ascending/Descending).
- **Interactive Previews:** Detailed modals providing artist info and high-resolution views.

---

## Use Case Scenario

| Actor | Action | System Response |
| :--- | :--- | :--- |
| User | Types in the search bar | System updates the gallery view with matching artworks. |
| User | Selects a category from the sidebar | System filters results to only show items in that category. |
| User | Changes sorting to "Price: Low to High" | System reorders the displayed artworks by price. |
| User | Clicks on an artwork card | System opens the `ArtworkDetailModal` with full description and artist profile link. |
